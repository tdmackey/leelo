# Leelo mascot

`leelo-mascot-v1.png` is the first Leelo mascot image.
The image has a transparent background.
The built-in image generation tool created the image from [this prompt](leelo-mascot-v1.prompt.txt).

The character has an orange hair tuft and holds an oversized multipass.
The design is deliberately too cute to suggest authority.

Keep the original file when you create a new version.
